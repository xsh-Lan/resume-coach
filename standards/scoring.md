# 简历雷达统一评分标准

总分 100 分。任何岗位、任何简历都必须使用同一套口径。

## 六个维度

| 维度 | 分值 | 权重说明 |
|---|---:|---|
| 岗位匹配 | 25 | 目标岗位是否明确，经历是否直接或可迁移地支撑 JD |
| 经历质量 | 25 | 业务背景、个人贡献、方法、交付物、结果是否完整 |
| 量化与证据 | 20 | 规模、效率、质量、转化、业务结果的覆盖率和可信度 |
| 结构与阅读 | 15 | 第一屏、模块顺序、信息密度、格式一致性、ATS 可解析性 |
| AI/数据专项 | 10 | 技术闭环、评测、方法选择、上线/采用、业务价值 |
| 语言与诚信 | 5 | 无空话、无夸大、术语统一、预计/实际结果区分 |

## 每个维度的评分区间

| 区间 | 含义 |
|---|---|
| 90%-100% | 可直接投递，证据链完整 |
| 75%-89% | 核心成立，需要局部补证据和重写 |
| 60%-74% | 可投递，但必须优先补强，不建议原样投高竞争岗位 |
| 45%-59% | 素材存在，但叙事分散、证据不足 |
| 0%-44% | 定位不清、证据不足或诚信风险高 |

## 评分规则

1. 每个维度先列出支持证据，再给分。
2. 不能只给总分，必须给六维分和总分。
3. 没有证据的项目不得给对应维度的分数。
4. 预计、目标、计划不能按已完成结果计分。
5. 同一维度同时存在强证据和严重诚信风险时，诚信风险优先降级。
6. 报告必须写“评分依据：……”而不是只给数字。

## 统一 Scorecard 模板

```text
综合体检：xx/100
- 岗位匹配：xx/25
- 经历质量：xx/25
- 量化与证据：xx/20
- 结构与阅读：xx/15
- AI/数据专项：xx/10
- 语言与诚信：xx/5
```

## 关键风险标记

- `P0`：事实、所有权、时间真实性、量化口径问题。
- `P1`：经历结构、主叙事、岗位匹配问题。
- `P2`：语言、排版、ATS、术语问题。
