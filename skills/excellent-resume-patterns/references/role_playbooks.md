# 岗位能力与证据手册

## AI / 大模型产品

必须展示：

1. 场景与用户问题。
2. Agent、RAG、Workflow、MCP、Prompt 或模型评测中的关键选择。
3. 数据/知识输入、模型处理、人工复核、兜底和反馈回流。
4. 准确率、效率、成本、WAU、API 或收入结果。

常见问题：只有技术名词，没有闭环；只有计划，没有上线；只写模型能力，不写用户价值。

## 数据产品 / BI

必须展示：

1. 指标治理、数据质量、口径统一或权限。
2. Dashboard、平台、API、自助分析或指标系统。
3. 用户采用、迁移、使用深度。
4. 成本和效率结果。

常见问题：把 BI 写成纯取数；只有工具，没有数据资产和业务决策。

## 商业分析 / 数据分析

必须展示：

1. 业务问题和数据范围。
2. SQL/HQL/Python、漏斗、归因、留存、AB Test、ROI 或预测模型。
3. 数据结论如何转成策略、预算、补贴、推荐或运营动作。
4. GMV、ROI、转化、成本、留存和风险结果。

常见问题：只有“分析了数据”；没有基线、结论和决策。

## 增长 / 运营 / 电商

必须展示：

1. 用户、商家、达人或渠道分层。
2. 活动、权益、触达、投放或内容机制。
3. 拉新、留存、转化、复购、GMV 和 ROI。
4. 复盘和 SOP。

常见问题：只写执行过程；没有规模、转化和收益。

## B 端 / 技术产品 / 平台产品

必须展示：

1. SDK、API、控制台、文档、配置或平台能力。
2. 客户接入、交付范围、研发协同和上线。
3. 客户价值：效率、成本、合格率、转化。
4. 商业化：签单、续签、采用和调用量。

常见问题：只写需求设计；不写交付复杂度和商业结果。

## 供应链 / 采购 / 物流

必须展示：

1. 计划、交付、质量、库存、成本。
2. 供应商规模、风险、绩效和协同。
3. 数据、仿真、预测或流程优化。
4. 准时率、利用率、周转、成本和质量结果。

常见问题：只写 KPI 名称；没有改善结果和决策价值。
