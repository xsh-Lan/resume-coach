# 简历写作系统

## 1. 先选主叙事

### 同岗位直申

`教育背景 → 相关实习 → 项目 → 技能证书`

### 跨专业转岗

`定位 → 教育中的迁移能力 → 相关项目 → 相关实习 → 技能`

### 经历较杂

把经历重组为 2-3 条主线，例如：

- 用户与产品线
- 数据与增长线
- 项目与商业化线

不要按时间把所有经历平均铺开。

## 2. 单段经历结构

```text
[工作概述] 为 [业务/用户目标]，负责 [范围]，通过 [方法] 推动 [结果]。
- [主题词]：针对 [问题]，通过 [方法/工具]，完成 [动作/交付]，实现 [结果]。
```

每条 bullet 只表达一个主题。优先使用稳定的主题词：需求分析、竞品调研、方案设计、数据建模、增长策略、实验分析、交付推广、成本优化。

## 3. 量化阶梯

| 层级 | 可写内容 |
|---|---|
| 规模 | 用户、商家、项目、城市、国家、供应商、SKU |
| 范围 | 模块、需求、报表、看板、原型、流程 |
| 频率 | 每日、每周、每月处理量 |
| 效率 | 时间缩短、人效提升、自动化率 |
| 质量 | 准确率、合格率、失误率、漏判率 |
| 转化 | CTR、CVR、留存、召回、提袋率 |
| 业务 | GMV、ROI、收入、成本、市值 |
| 影响 | 决策、流程、风险、客户采用 |

没有精确数字时，用范围、频率、交付物、效率和质量量化，不得编造。

## 4. 高价值动词

- 分析：拆解、定位、归因、验证、复盘、测算、分层、建模
- 产品：定义、设计、重构、抽象、搭建、迭代、评审、上线、灰度
- 运营：拉新、召回、转化、触达、孵化、投放、建联、拓展
- 项目：主导、统筹、协同、推动、交付、沉淀

## 5. 24 个可套用句型

1. 通过 `[问卷/访谈]` 定位 `[用户/场景]` 的核心痛点并形成优先级。
2. 调研 `[N]` 个竞品，按 `[维度]` 建立对比矩阵并提炼可借鉴点。
3. 设计 `[输入—处理—输出—复核—反馈]` 闭环并推动上线。
4. 主导从 0 到 1 建设 `[产品/平台]`，覆盖 `[范围]` 并交付结果。
5. 重构 `[流程/配置/入口]`，降低 `[门槛/成本]`，提升 `[效率]`。
6. 基于 `[数据/规则]` 抽象 `[能力]`，形成可复用 `[模板/组件]`。
7. 设计 `[灰度/AB/试点]` 和指标，根据反馈迭代。
8. 从行为数据定位关键流失节点并设计优化功能。
9. 设计 RAG/知识库机制，为模型返回判断依据和案例。
10. 设计 Agent/Workflow 的节点、工具、调用和兜底。
11. 制定 Prompt、评测集、人审和 badcase 回流机制。
12. 建立准确率、误判率、漏判率和人审率指标体系。
13. 从数仓/埋点提取数据并按漏斗、分层或归因拆解。
14. 搭建日报、指标树或 Dashboard，细化分析粒度。
15. 设计 AB Test，明确效果和约束指标并推动策略。
16. 用回归、时序、聚类或分类模型验证业务假设。
17. 对用户、商家或渠道分层并制定差异化策略。
18. 设计活动机制、权益组合和站内外触达。
19. 复盘活动数据和反馈并沉淀活动矩阵与 SOP。
20. 从公海、竞对或存量对象拓展增量。
21. 统筹团队在期限内完成项目并协调多方交付。
22. 将重复工作自动化，缩短周期并沉淀流程。
23. 按计划、交付、质量、库存和成本优化供应链。
24. 建立供应商绩效与风险框架并推动改进。

## 6. 自我评价改写

不要写“学习能力强、沟通能力强、抗压能力强”。

改成可验证句：

- `转岗适应力：原专业背景已通过 [项目/实习] 完成 [能力] 迁移，产出 [结果]。`
- `结构化分析：用 [漏斗/指标体系/假设验证] 定位问题并推动 [结果]。`
- `执行力：在 [约束] 下完成 [交付物]，推动 [节点] 上线。`
