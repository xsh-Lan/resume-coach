# 用户事实库

Offer 雷达长期使用的本地事实层。姓名和联系方式不落盘。

## 文件

| 文件 | 用途 |
|---|---|
| `candidate_profile.md` | 候选人画像：背景、经历、项目、技能、求职方向 |
| `evidence.json` | 结构化事实、证据状态、量化指标 |
| `gap.json` | JD 差距、待补事实、待核验信息 |
| `versions/` | 每次重大改写的版本快照 |

## 更新规则

1. 先读取现有文件，增量更新，不从零重写。
2. 事实状态使用：`verified`、`unclear`、`missing`、`expected`。
3. 姓名和联系方式不写入任何事实库文件。
4. 所有数字保留原始口径；不确定就标记 `unclear`。
